# M1 인증·거래방 분리 설계

## 목표

- 공개 데모의 익명 쓰기를 막고, 방 단위 권한을 만든다.
- 집톡이 없이 M1만으로 거래방이 안전해진다.

## 범위

- Supabase Auth 로그인 UI(임대인·임차인 구분).
- 방 분리: `deal_rooms` 신설. `room_id`로 메시지·방문·합의·체크를 묶는다.
- 마이그레이션 003: 방 테이블 + 기존 listing_id 데이터 이관.
- 조회·쓰기 전부 참여자 검사. 방 멤버가 아니면 403.
- dev 별명은 로컬 전용으로 격리. 운영에서는 비활성화.

## 수용 기준

- 토큰 없이 쓰면 401. 남의 방 조회하면 403.
- 방 생성·초대·참여 테스트 통과.
- 기존 시드 매물 열람은 로그인 없이 가능.

## 비범위

- 집톡이, UI 개편, 결제.
