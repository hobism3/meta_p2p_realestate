# DirectHome v2 법률 검토

주의: 이 문서는 법률 자문이 아니다. 자문 완료로 간주하지 않는다.
검증되지 않은 해석은 전부 미확인으로 표시한다.
공식 확인처: 국가법령정보센터 법령 원문. 이 세션에서 원문 대조는 하지 않았다.

## 1. 공인중개사법

- 쟁점: 플랫폼 기능이 중개행위·알선으로 해석될 여지가 있는지.
- 확인할 것: 중개행위 정의 조항, 무등록 중개 금지 범위, 표시·광고 규제.
- 상태: 미확인. 원문 대조와 전문가 자문 필요.
- 설계 가드레일: 거래 상대방 연결·교섭 대행·성사 수수료를 받지 않는다. 정보 제공과 정리 지원에 머문다.

## 2. 부동산 거래신고법

- 쟁점: 직거래 당사자의 거래신고 의무 안내가 필요한지.
- 참고(2차 출처 기반, 원문 미대조): 거래계약 체결일부터 30일 이내 신고(제3조 취지), 해제·무효·취소 시 해제 확정일부터 30일 이내 신고(제3조의2 취지), 주택 임대차 신고(제6조의2 취지).
- 상태: 미확인. 조항 번호와 현행 시행일은 원문 대조 필요.
- 설계 가드레일: 체크리스트에 신고 의무 안내를 넣는다. 신고 대행은 하지 않는다.

## 3. 표시·광고

- 쟁점: 허위·과장 매물 표시 책임, 게시자 확인 상태 표시의 표현 수위.
- 확인할 것: 표시광고법, 공인중개사법상 허위표시 관련 규정.
- 상태: 미확인.
- 설계 가드레일: 확인 상태를 사실 기반으로만 표시한다. 예: 본인 인증 완료, 소유 확인 서류 제출됨. 안전·보증 표현 금지.

## 4. 개인정보

- 쟁점: 등기부·신분증 등 민감 정보 수집·보관·AI 전달.
- 확인할 것: 개인정보보호법상 민감정보 처리 요건, 보관 기간, 제3자 제공 고지.
- 상태: 미확인.
- 설계 가드레일: 최소 수집, 마스킹 후 AI 전달, 원본 접근 권한 분리, 보관 기간 명시.

## 5. 변호사법

- 쟁점: AI 계약서·특약 생성 지원이 법률사무 취급으로 해석될 여지.
- 확인할 것: 법률사무 범위 판례·유권해석.
- 상태: 미확인.
- 설계 가드레일: 자동 특약 확정은 제외한다. AI는 조건 정리와 미확인 사항 안내만 한다. 전문가 검토 권유 문구를 항상 붙인다.

## 6. 제외 행위(하지 않기로 한 것)

- 유료 알선: 중개행위 해석 위험 때문에 제외.
- 자동 특약 확정: 법률사무 해석 위험 때문에 제외. 초안 성격의 문구도 MVP에서 빼고, 체크리스트와 정리로 한정.
- 계약금 보관: 자금 보관·정산 규제 위험 때문에 제외.
- 상태: 사업 정책으로 확정. 법률적 최종 판단은 자문 후.

## 7. 법률상 미해결 항목

1. 중개행위 해당 여부 경계선(원문 대조+자문).
2. 거래신고법 조항 번호·시행일 원문 대조.
3. 표시·광고 표현 수위 기준.
4. 민감정보 보관 설계의 적법성.
5. AI 지원 범위의 법률사무 해당 여부.
6. 외부 전문가 자문 일정 자체가 미확정.
