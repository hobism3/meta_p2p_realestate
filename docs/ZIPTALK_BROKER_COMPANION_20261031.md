# 집톡이 - 동네 부동산 친구 UX

작성: 2026-10-31 / 검토용 변경

## UX의 역할 전환

기존에는 상담사처럼 별도 창에서 분석 기록을 열람했다. 이번에는 집톡이가 대화에 끼어드는
말 많은 챗봇이 아니라, 옆에서 이야기를 듣고 적절할 때 한마디 해 주는 도우미로 표현한다.

1. **사이드 한마디**: 집톡이가 새 메모를 저장할 때에만 작은 말풍선으로 반응한다.
   일상 메시지에는 끼지 않고 중개수첩에서 과거 기록을 열 수 있다.
2. **3가지 챙길 일**: 가격 이야기, 방문 일정, 생활 조건 상태를 확인한다.
   실제 room_conditions/visits의 기록과 상태, 확인 버전을 근거로 표시한다.
3. **다음 질문 챙기기**: 방문 일정, 가격, 생활 조건 중 다음에 물어볼 질문을 제안한다.
   버튼은 입력창에만 문장을 넣고 자동 전송하거나 예약/계약을 확정하지 않는다.
4. **친근한 말투**: 동네 부동산 친구 같은 자연스러운 한국어 한마디를 표시한다.
   Meta 입력 프롬프트도 부드럽게 하되 계약 사실을 지어내거나 공인중개사인 척하지 않는다.
5. **방해하지 않기**: 입력창 포커스·타이핑·거래 현황 패널을 우선하며, 말풍선은 접을 수 있다.
6. **근거 기록 유지**: 서버 저장 방식과 기존 ProposalCard 동의·거절/근거 기능은 변경하지 않는다.

## 검증 기준

- 첫 방문에서는 미확정 상태로 인사만 하고, 근거 없는 사실을 만들지 않는다.
- '보증금 3천/월세 60' 제안을 계약 완료로 표시하지 않는다.
- '10월 31일 오후 3시'는 방문 제안, '수락됨'은 방문 확인으로 구분한다.
- 기존 수락 이후 새로운 방문 제안이 있으면 새 제안의 확인을 우선한다.
- 반려동물 관련 질문만으로 허용·금지 여부를 확정하지 않는다.
- 변경 제안 질문은 메시지 입력창에만 채우고 DB 쓰기를 발생시키지 않는다.
- PC와 모바일에서 팝업, 메모, 제안 카드, 입력, 거래방 재입장 E2E 검증.
