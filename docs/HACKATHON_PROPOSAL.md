# 해커톤 제안서: DirectHome v2

## 1. 대회

- Meta Global AI Developer Hackathon 2026, Build for Your World.
- 개발 도구: Muse Code.
- 서비스 내부에 실제 Meta Muse Spark API를 연결한다.

## 2. 문제

- 소형 월세 직거래에서 임차인은 무엇을 확인해야 할지 모른다.
- 집주인은 중개보수 없이 직접 구하고 싶지만 신뢰 장치가 없다.

## 3. 해결

- 조건 합의와 거래 준비를 관리하는 직거래 플랫폼.
- AI는 조건 정리와 미확인 사항 안내만 한다.
- 체크리스트로 거래 준비를 끝까지 돕는다.

## 4. 데모 시나리오(가상 매물 기반)

1. 임차인이 지도로 가상 매물을 찾는다.
2. 매물 상세에서 확인 상태를 본다.
3. 문의하고 방문 일정을 잡는다.
4. 거래방에서 조건을 합의한다.
5. AI가 조건을 정리하고 미확인 사항을 알려준다.
6. 체크리스트를 완료하고 거래를 준비한다.

## 5. 평가 포인트

- 실제 Muse Spark 연결과 근거 있는 AI 출력.
- 법률 경계를 지킨 설계(판단·확정 기능 제외).
- 합의부터 준비까지 끊기지 않는 흐름.

## 6. MVP 범위

- PRODUCT_PRD 6개 기능. 가상 매물 시드 포함.
- 제외: 유료 알선, 자동 특약 확정, 계약금 보관, 결제·서명 연동.

## 7. 미확정 사항

- 데모 지역, 가상 매물 수, 발표 자료 구성.
