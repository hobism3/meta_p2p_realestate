# DirectHome v2 사업 모델

## 1. 사업 목표

- 집주인과 임차인이 중개보수 부담을 줄이면서 직접 거래하는 전문 부동산 플랫폼.
- 장기 목표는 실제 창업과 수익화다.
- 해커톤 MVP는 가상 매물 기반으로 거래 준비 흐름을 증명한다.

## 2. 초기 고객

- 소형 주택 월세 직거래를 원하는 개인 임대인·임차인.
- 초기에는 특정 지역에 집중한다.
- 미확정: 대상 지역 1곳 선정, 대학가·역세권 등 기준 확정 필요.

## 3. 고객 문제

- 임대인: 수수료를 내기 아까운데, 직접 구하면 허위 문의와 사기 걱정이 크다.
- 임차인: 직거래 매물은 조건이 불투명하고, 무엇을 확인해야 할지 모른다.

## 4. 차별화

- 당근·직방처럼 매물 수로 승부하지 않는다.
- 매물을 찾은 후 조건 합의와 거래 준비를 체계적으로 관리한다.
- AI는 판단이 아니라 정리를 돕는다. 조건 요약과 미확인 사항 안내에 한정한다.

## 5. 수익 모델 가안(장기)

- 기본 매물 등록·검색은 무료로 둔다.
- 유료 후보: 거래 준비 리포트, 안심 체크 패키지, 임대인 인증 뱃지.
- 제외: 거래 성사 수수료(중개보수 형태), 유료 알선, 계약금 보관은 하지 않는다.
- 미확정: 과금 포인트와 가격. 법률 검토 후 확정한다.

## 6. 비용 구조 가안

- Muse Spark API 호출료.
- 본인·소유자 확인 서비스 이용료.
- 서버·스토리지 운영비.
- 미확정: 월 예상 호출량과 단가.

## 7. 핵심 지표 가안

- 매물 등록 수, 합의 도달률, 체크리스트 완료율.
- AI 요약 유용성 평가(주관식+평점).
- 미확정: 지표 목표치.

## 8. 기존 기획 대비 차이

- v1(planning.md)은 매매까지 포함하고 등기부 자동 분석과 특약 자동 생성을 전제로 했다.
- v2는 월세·특정 지역으로 좁히고, AI 자동 판단을 빼고 정리·안내 역할로 한정한다.
- 이유는 법률 리스크 회피다. 상세는 LEGAL_REVIEW를 본다.

## 9. 미확정 사항

- 대상 지역, 과금 포인트, 지표 목표치, 스택.
