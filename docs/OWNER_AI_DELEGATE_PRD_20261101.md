# DirectHome — 집주인 AI 대리 운영 서비스 기획서
**버전:** PRD v0.1 / 2026-11-01
**상태:** Phase 1 구현 착수. 실제 자동 응대/알림/예약은 후속 단계.

## 1. 제품 가설
집주인이 직거래 매물을 등록한 뒤 문의 응대, 방문 일정 관리, 거래 조건 확인에 쓰는 시간을 줄인다. 집주인이 매물별 지식, 방문 가능 시간과 AI 권한을 설정하면 AI가 *허용된 범위에서만* 안내하며 결정이 필요한 문제는 집주인에게 전달한다.

- 임대인/매도인: 반복 답변 감소, 예약 시간 충돌 회피, 중요한 의사결정은 직접.
- 임차인/매수인: 즉시 정보 확인, 방문 가능 시간 및 응답 상태 투명화.
- 집톡이: 양측 거래방에서 합의 여부·계약 준비를 관리. 임대인 AI와 별도 정체성.

## 2. 정보 구조
1계정/2모드: '집 찾기'와 '내 집 관리'. 권한은 사용자 표시 모드가 아닌 매물의 owner_id를 기준으로 판단한다.
- `/owner`: 내 매물 현황, 문의방 수, 승인 필요 요청, AI 상태.
- `/owner/listings/[id]`: 매물별 AI 대리인 설정, 방문 가능 요일/시간, 수동 확인 대상.
- `/register`: 매물 자체의 사실 정보만 입력. 완료 후 내 매물 관리 링크 제공.
- 기존 거래방 `/rooms/[rid]`: 양측 대화와 집톡이. AI 대리인은 '집주인을 대신한 AI 응대'를 명시한다.

## 3. 자동화 권한 정책
|등급|행위|기본 동작|
|---|---|---|
|A: 사실 조회|가격·면적·옵션·입주 정보|DB에 등록된 사실만 답변|
|B: 시간 안내|방문 가능 시간|저장된 시간 규칙만 안내, 실제 예약 확정 아님|
|C: 승인 조건 예약|예약 생성·변경·취소|서버 슬롯·중복·권한 검증 후 실행, 집주인 승인 모드 지원|
|D: 집주인 판단|가격 조정, 특약, 반려동물 예외, 계약 내용|AI는 승인 요청만 생성; 거절/승인 권한 없음|
|E: 고위험|송금, 법적 계약서명, 소유권 보장|자동 처리 금지|

기본값 AI OFF, 자동 예약 OFF, 승인 요청 모드. AI 동작에는 사용자 고지와 감사 로그가 필요하다.
LLM이 모르는 예약 시간을 만들어 답하지 못하도록 가격/옵션/방문 시간은 구조화된 정책·DB에서 조회한다. **시연용 AI 임대인의 자율 제안 프롬프트를 실매물에 그대로 연결하지 않는다.**

## 4. 방문 예약 상태 모델
방문 가능 주간 반복 규칙(요일, 시작/종료 시간, Asia/Seoul 기준) → 가용 슬롯 조회 → 요청 `requested` → 승인(`confirmed`)/거절(`declined`) 또는 승인된 자동 예약 → 변경/취소. 겹치는 요청은 DB 트랜잭션으로 거부한다. 방문 전 알림과 리마인더는 승인된 예약만 대상으로 하며 발송 채널·동의를 기록한다.

## 5. 구현 단계
- **P1**: 소유자 전용 목록 + 매물별 AI 응대 설정/방문 가능 시간 입력과 영속 저장; 접근 권한 검증; 매물과 거래방을 연결한 문의 건수 표시. (이번 PR)
- **P2**: 집주인 대리 답변 엔진(사실기반 QA, 승인 필요 분류, 수동 전환, 감사로그) + 소유자 알림함.
- **P3**: 실제 슬롯 예약 서비스(동시성/시간대/변경·취소), 승인/자동확정 모드, 알림 발송/리마인더.
- **P4**: 집톡이 거래 진척 연계(방문 후 계약/잔금), 분석 및 결제 가설 검증.

## 6. 성공지표·수익화 가설
문의 중 자동 해결 비율, 소유자 확인 소요시간, 방문 예약 전환율, 예약 취소율, 허위/오안내율(목표 0), 재사용률.
무료 등록/기본 관리 + 매물 단위 30일 AI 이용권(가설 9,900~19,900원). 고객 인터뷰·A/B 가격 실험 전까지 유료 검증치 아님.
법적 역할(중개업 해당 여부), 개인정보·알림 동의, 진정한 소유권/관리 위임 여부는 운영 전 별도 검토.

## 7. 수락 기준(P1)
- 등록한 본인 매물만 내 집 관리에 표시되고, 타인 계정은 설정을 읽거나 수정할 수 없다.
- 방문 가능 시간은 월~일, HH:mm, 시작<종료 검증. 시간대는 Asia/Seoul.
- AI 기본 OFF; 자동 예약 아직 미구현이므로 UI에서 예약 '자동 확정'을 제공하거나 실제 응답할 수 있다고 주장하지 않는다.
- 시드/합성 시연 매물은 '내 매물' 소유물로 변조할 수 없다.
- 새 UI는 모바일 폭에 대응한다. 모든 저장은 실패·성공 피드백 제공.
