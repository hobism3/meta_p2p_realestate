## 전제 / 사용자 수정 요구
- 사용자는 부동산 등기 해석 전문 지식이 없어 **직접 문서별 정답 라벨을 만들 수 없음**. 이전 P11의 '사람이 골든 원문을 전수 라벨링' 필요조건을 폐기.

- 현재 `status=unknown`, 사용자에게 자동 현행/말소 판정 또는 계약 효력 부여 없음.

## 4. 개선됐다고 말할 수 있는 수준
- 외부 HUG 교육용 표의 **20억**을 프로그램이 정확히 채권최고액으로 읽고 날짜·구역을 연계할 때만 **그 부분 필드가 외부 발행자 자료와 일치**했다고 말할 수 있다.
- 공개 가상 PDF 5종과 발행자 해설의 '가압류/경매/근저당/확정일자'는 교육용 범위에서 검증. 실제 법적 효력/말소선은 모름.
- 공식 기관/HF/법령 자료의 공통 분류 규칙을 지킨다고 해서 같은 실제 집의 임차보증금 반환이 안전해지는 것은 아니다.
- 정확도/재현율·false-safe rate 같은 수치는 **완전한 정답 분모가 없어 산출 불가**. 추출 가능한 관찰형 번호행 중 일치 비율은 파서의 내부 일관성 지표이며 precision/recall의 대체가 아니다.
