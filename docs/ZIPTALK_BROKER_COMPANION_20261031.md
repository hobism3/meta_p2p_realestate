# 집톡이 그룹채팅 진행 도우미
집톡이는 별도 상담사 창이나 독립 수첩이 아니라 임대인과 임차인이 함께하는 그룹채팅의 세 번째 참여자다.

- 같은 거래 타임라인 안에 집톡이의 메시지를 표시한다.
- 집톡이의 메시지 바로 아래 조건 합의 카드를 표시하며 각 당사자의 명시적 동의가 있어야 확정된다.
- 상단 진행 체크는 가격, 방문, 생활 조건과 남은 절차를 보여준다. 가격은 한쪽 확인만으로 완료가 되지 않는다.
- 가격을 절충하거나 새로운 중재안을 제안하지 않는다. 합의 성립 여부는 시스템의 동의 상태로 결정한다.
- 새 방문 일정이 제안되면 이전 수락과 구분해 재확인이 필요함을 알린다.
- 실제 매물/거래방에 AI 임대인이나 집톡이가 자동으로 끼어들지 않는다. 시연방 기능이다.

검증: PR 브랜치의 빌드, 단위 테스트, E2E 및 Vercel Preview 상태를 확인한 뒤 병합한다.
