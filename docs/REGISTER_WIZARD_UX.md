# DirectHome - 단계별 매물 등록 UX 개선

2026-10-30. 구현 후보, 배포 전 검토 대상.

## 목표와 방향

긴 입력 폼 대신 모바일 앱처럼 단계가 자연스럽게 진행되는 웹 UX를 만든다. 네이티브 앱은 필요하지 않으며 기존 Next.js와 React만으로 동작한다.

## 등록 흐름

1. 시작: 교육용/가림처리 PDF를 AI로 읽거나 직접 입력.
2. 공간: 매물명, 주소, 전유면적. PDF 결과는 사용자 확인 뒤 적용.
3. 거래: 월세/전세/매매를 카드로 선택, 필요한 가격 항목만 표시.
4. 생활: 입주일, 관리비, 옵션, 소개, 게시자.
5. 검토: 각 단계의 값을 확인하고 수정한 뒤 최종 등록.

## 설계 원칙

- 상단 단계 진행, 모바일 터치 영역, 전환 효과(모션 감소 설정 지원).
- PC의 우측에 실시간 매물 요약, 작은 화면에서는 폼 집중.
- 단계별 필수항목 검증 및 포커스 안내. 이전 단계로 돌아가도 입력 유지.
- 현재 탭 sessionStorage에 텍스트 필드/단계만 임시 저장. PDF 원본, Meta 응답, 전송 동의는 저장하지 않음.
- 사용자가 초기화를 누르면 확인 대화 후 임시 값 삭제.
- 기존 API의 POST/PATCH 계약과 편집 페이지의 거래유형 잠금 유지.
- 최종 버튼을 누르기 전에는 게시되지 않음. AI 추출은 소유권/법적 검증이 아님.
- 운영 데이터가 아닌 시연용 합성 데이터만 사용.
