# DirectHome v2 제품 요구사항(PRD)

## 1. 개요

- 집주인·임차인 월세 직거래. 특정 지역 집중.
- 매물 발견 이후의 조건 합의와 거래 준비를 관리한다.
- AI는 정리와 안내만 한다. 판단·확정은 하지 않는다.

## 2. 핵심 기능

### 2.1 집주인 직접 매물 등록

- 입력: 주소, 면적, 보증금, 월세, 관리비, 입주 가능일, 사진, 설명.
- 출력: 매물 카드와 상세 페이지.
- 수용 기준: 필수 항목 누락 시 등록 불가. 허위 신고 버튼이 보인다.
- 미확정: 본인·소유자 확인 수단(서류 업로드 vs 외부 인증).

### 2.2 지도·리스트 매물 검색

- 입력: 지역, 보증금·월세 범위, 입주 시기.
- 출력: 지도 핀과 리스트. 가상 매물 기반.
- 수용 기준: 조건 필터가 동작한다.
- 미확정: 지도 SDK 선정.

### 2.3 매물 상세 및 게시자 확인 상태

- 표시: 매물 정보, 확인 상태(사실 기반만), 신고 버튼.
- 금지 표현: 안전, 보증, 검증 완료 같은 단정 표현.
- 미확정: 확인 상태 항목 정의.

### 2.4 문의·방문 일정·거래방

- 문의 메시지와 방문 일정 제안·수락.
- 거래방에서 합의 내용을 로그로 남긴다.
- 수용 기준: 일정과 합의 로그가 남는다.
- 미확정: 알림 수단(이메일 vs 푸시).

### 2.5 AI 거래 조건 정리 및 미확인 사항 안내

- 입력: 거래방 대화·합의 내용, 매물 정보.
- 출력: 합의된 조건 요약, 금액·날짜 표, 미확인 사항 목록.
- 원칙: 등급·판단·특약 문구 생성 금지. 모르는 것은 미확인으로 둔다.
- 수용 기준: 요약에 근거(어디서 나온 말인지)가 붙는다.
- 미확정: Muse Spark 프롬프트와 출력 스키마.

### 2.6 거래 준비 체크리스트

- 항목: 신분 확인, 소유자 확인, 대리인 위임장, 관리비 체납, 확정일자, 전입신고, 거래신고 의무 안내.
- 수용 기준: 항목별 완료 체크와 메모가 저장된다.
- 미확정: 항목별 증빙 방식.

## 3. 비범위

- 유료 알선, 자동 특약 확정, 계약금 보관.
- 전자서명·결제 연동, 실거래가 검증, 보증보험 연계, 모바일 앱.

## 4. 기존 기획·코드 대비 차이

- 기존 docs/planning.md v1: 등기부 파서+위험 등급, 특약 자동 생성, 매매 포함.
- v2 변경: 등기부 자동 분석 삭제, 특약 생성 삭제, AI는 조건 정리로 축소, 월세·특정 지역으로 축소.
- 기존 muse_test_app: 범용 HTTP 데모. 도메인 로직 없음. 재사용 대상 아님. 테스트 분리 패턴(resolve_get)만 참고한다.
- 기존 파일은 삭제하지 않고 보존한다. v1 문서는 역사 기록으로 둔다.

## 5. 미확정 사항

- 확인 수단, 지도 SDK, 알림 수단, 체크리스트 증빙, 프롬프트·스키마, 스택.
