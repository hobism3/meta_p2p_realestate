## 공통 게이트

1. `next build` 통과.
2. `node --test tests/` 전부 통과. 실패 숨김 금지.
3. 신규·변경 API는 통합 테스트에 케이스 추가.
4. 스모크: 페이지·API 200 확인(로컬 또는 운영).
5. 문서·백로그·로그 갱신.
