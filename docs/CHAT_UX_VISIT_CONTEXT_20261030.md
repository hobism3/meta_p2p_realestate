# DirectHome - 대화 UX 및 방문시간 복구

날짜: 2026-10-30. 개발 브랜치 기준.

## 방문 일정 오류 재현
사용자는 오후 3시로 변경을 질문했고 AI 임대인은 내일 오후 세시에 뵐게요라고 답했다.
2026-10-30 기준 방문 제안은 2026-10-31 15:00이다.
기존 파서는 숫자 시간은 처리했지만 한글 세시를 놓쳐 시간을 정해 달라고 잘못 안내했다.

## 코드 변경
- visit-dates.ts: 한글 시각을 파싱하고 앞선 날짜와 연결한다.
- ziptalk-service.ts: 뵐게요, 보고 싶어요 등 방문 문맥을 인식하고 근거 ID를 보존한다.
- Meta 모델이 날짜만 기록해도 원문에 명시된 시간을 제안(proposed)으로 보완한다.
- 추가 유료 Meta 모델 호출 없음. 방문을 자동 수락/확정하지 않는다.
- 사용자의 시각 변경 질문만으로는 예약 제안을 새로 만들지 않는다.

## UX
- 채팅 로그에서 집톡이 메시지를 분리해 전용 집 모양 캐릭터 팝업에서 확인한다.
- 기존 제안/합의 카드 및 거래 현황 연결은 유지한다.
- 새 집톡이 정리가 생기면 표시하지만 입력창 포커스 및 거래 현황 열림 시 접는다.
- 메신저 말풍선, AI 답변 중 표시, 빠른 질문, 키보드 입력, 모바일 스타일 개선.
- 내 거래방 검색, 전체/AI 시연/개인 거래 필터와 빈 상태 안내.

## 검증
- 합성 대화와 가짜 Meta 서버로 HTTP 및 SQLite 검증. 실제 Meta 과금 0회.
- 원본 운영 DB/개인정보 및 실매물 변경 없음.
- Next.js build, 단위/DB, PC·모바일 Playwright 및 기존 거래방·등록 회귀 확인.
- 완료 전 main/Production 배포 금지. PR Preview에서 디자인 검토.

## 후속 UX 후보
- 날짜 변경 제안 이력/중복 후보의 시각적 구분.
- 채팅 검색, 읽음 상태, 첨부파일 미리보기.
- 집톡이 알림 빈도/접기 설정 및 접근성 개선.
